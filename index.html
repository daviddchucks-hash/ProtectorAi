Features

Everything you need to secure your site

Beast AI gives you full visibility into what's happening on your website — without any complex setup or third-party services beyond Firebase.

👥

Visitor Tracking

Every visitor is fingerprinted by browser, OS, device, language, timezone, and screen size. See who's online right now and their full session history.

🐛

JS Error Capture

Catches uncaught exceptions, unhandled promise rejections, and console errors in real time. Know about crashes before your users complain.

⚡

Behavior Detection

Detects rapid click bursts, abnormal form submission patterns, failed resource loads, and other suspicious behavioral signals automatically.

🎯

AI Risk Scoring

Every event gets a risk score from 0–100. Events are classified as Low, Medium, High, or Critical so you know exactly where to focus attention.

⏱

Performance Monitoring

Measures real page load times across your visitor base. Track average load time in the dashboard and catch performance regressions fast.

🚨

Alerts & Actions

High and Critical events automatically surface as alerts with recommended actions. Resolve them in one click directly from the dashboard.

How it works

Up and running in minutes

Beast AI is designed to require as little setup as possible.

1

Deploy the server

Deploy the Beast AI Node.js server to Render (or any Node host). It connects to your Firebase Firestore for storage.

2

Add the script tag

Paste one <script> tag before </body> on every page you want to monitor.

3

Open the dashboard

Visit /dashboard on your deployed URL. Events start streaming within seconds.

4

Act on alerts

High and Critical alerts appear instantly. Review visitor details, event history, and resolve threats in one click.

Risk Engine

Four-tier threat classification

Every event Beast AI captures gets scored 0–100 and classified into one of four risk tiers, so you can immediately prioritize what matters.

Low 0 – 24

Normal activity. Regular page views, sessions, and standard user behavior. No action needed.

Medium 25 – 49

Unusual but not alarming. Slightly elevated activity worth keeping an eye on over time.

High 50 – 74

Suspicious behavior detected. Review recommended — rapid clicks, repeated errors, or failed resources.

Critical 75 – 100

Immediate attention required. Potential attack or serious anomaly. Act on these alerts right away.

Installation

Get started in 3 steps

Beast AI requires a Firebase project for storage and a Node.js host like Render. See the Render deploy guide and Firebase setup for full instructions.

Add this tag before </body> on every page you want to monitor: 

<!-- Beast AI — add before </body> -->
<script src="https://YOUR-APP-NAME.onrender.com/beast.js"></script>

Replace YOUR-APP-NAME with your Render deployment URL. Beast AI initialises automatically — no further configuration needed on the client.

Copy .env.example to .env and fill in your values: 

# Firebase Admin SDK
FIREBASE_PROJECT_ID=your-project-id
FIREBASE_PRIVATE_KEY="-----BEGIN PRIVATE KEY-----\n..."
FIREBASE_CLIENT_EMAIL=firebase-adminsdk@your-project.iam.gserviceaccount.com

# CORS — allowed origins (comma-separated)
ALLOWED_ORIGINS=https://yourdomain.com

# Dashboard access token (use a strong random string)
DASHBOARD_TOKEN=change-me-to-a-strong-secret

# Your Render deployment URL
RENDER_URL=https://your-app.onrender.com

See docs/firebase-setup.md for step-by-step Firebase configuration.

Install dependencies and start the server:

# Clone the repository
git clone https://github.com/daviddchucks-hash/ProtectorAi.git
cd ProtectorAi/ProtectorAi

# Install dependencies
npm install

# Copy and configure environment
cp .env.example .env
# Edit .env with your Firebase credentials

# Start development server
npm run dev

For production, deploy to Render — see the full guide in docs/render-deploy.md.
